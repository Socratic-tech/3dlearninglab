MakeSpace Classroom Studio

Version 1.0. A browser-based place to explore connected dimensions, make predictions, test designs, and create STL files.

Models, supporting files, and notebooks stay in this browser on this device. MakeSpace has no accounts, analytics, or automatic model uploads. Save a Project ZIP to keep a backup or move to another device. External CAD links open their own services without transferring your model.

Open-source foundations

The application modules are provided as readable source alongside the site. MakeSpace application code is licensed under GPL-2.0. Third-party components retain their own licenses.

  • OpenSCAD WASM 0.0.4 · GPL-2.0. The included engine is unmodified from the published npm distribution. Upstream source and build instructions are available in its repository.
  • Three.js 0.187.0 · MIT.
  • fflate 0.8.3 · MIT.
  • opentype.js 1.3.4 · MIT.
  • Abel font by MADType · SIL Open Font License 1.1. Lettering is converted to outlines for consistent browser rendering. Imported font selections are substituted with this font.
  • PuzzleCAD 2.2 by Aaron Siegel · MIT. Bundled, unmodified library source files. The licenses on individual puzzle designs are separate from the library license.

MakeSpace is independent of OpenSCAD, SimpCAD X, and Tinkercad. Example designs are digitally checked, not physically certified. Classroom printing and physical testing remain part of the learning process.
