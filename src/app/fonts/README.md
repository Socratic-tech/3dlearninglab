Self-hosted fonts (SIL Open Font License 1.1), so the app works on school networks that block Google Fonts:
- Atkinson Hyperlegible — Braille Institute (body text, chosen for readability)
- Space Grotesk — Florian Karsten (headings)
- JetBrains Mono — JetBrains (numbers, code, dimensions)
Files come from the @fontsource packages.
