# UDL 3.0 alignment

How 3D Design Academy lines up with CAST's [UDL Guidelines 3.0](https://udlguidelines.cast.org/) (2024). Each
row names the consideration and where it shows up for students. "Every lesson" means the platform provides it,
so it applies to all 40 missions automatically. Audit date: October 2026.

## Engagement — the "why" of learning

| Consideration | Where it shows up |
|---|---|
| 7.1 Choice and autonomy | Pick-a-theme on themed challenges; **"Make it yours"** on every other challenge; choice of how to submit evidence; display looks (XP-unlocked) |
| 7.2 Relevance, value, authenticity | "In the real world" opener on every lesson; client requests on 32 challenges; real users in the design-process unit |
| 7.3 Joy and play | XP, streaks, daily goal, confetti, boss battles, fail gallery |
| 7.4 Address biases, threats, distractions | Low-stakes practice (try again, no penalty), "a wrong answer tells you something" framing, focused one-screen-at-a-time player; respectful, varied client names and roles |
| 8.1 Meaning and purpose of goals | **Today's goals** card on every lesson: the "I can…" statements and what it builds on |
| 8.2 Challenge and support | **"Need a hint?"** on 148 of 148 non-prediction questions (practice: open any time; skill checks: after a first try); explanation unlocks after repeated tries; teacher preview of every lesson |
| 8.3 Collaboration and collective learning | **Team option** on every micro and prove challenge (plan together, each builds their own); talk-it-through note on boss battles; teacher discussion questions |
| 8.4 Belonging and community | Showcase lesson, class print queue, peer-feedback practice in Maker Showcase |
| 8.5 Action-oriented feedback | Immediate "Test result" feedback with targeted hints on a wrong try; teacher review comments with "needs revision" |
| 9.1 Expectations, beliefs, motivations | Speed never affects grades (timer is awareness only); "Stuck? That's part of designing" |
| 9.2 Awareness of self and others | Reflection with sentence starters on every lesson; **Design for everyone** in Product Design; **Listen without assuming** in Interviewing a User |
| 9.3 Individual and collective reflection | Reflection block on every lesson; design journal; teacher discussion questions |
| 9.4 Empathy and restorative practices | User interviews, design-for-everyone, "Ask your teacher — say what you tried" |

## Representation — the "what" of learning

| Consideration | Where it shows up |
|---|---|
| 1.1 Customize the display | Display menu (Aa): text size, easier-to-read font, high contrast, reduced motion, light/dark, read-aloud speed, looks |
| 1.2 Multiple ways to perceive | Read aloud on every screen; diagrams with text descriptions; 3D models with spoken dimensions and keyboard controls; sliders that show change live |
| 1.3 Diverse perspectives and identities | Varied clients and users; accessibility as a design value (curb-cut example); interviews in a home language encouraged |
| 2.1 Vocabulary, symbols, structures | **Words you'll use** on the goal card and in the Stuck panel (every lesson has a vocabulary list) |
| 2.2 Decoding text and symbols | Read aloud; Markdown emphasis on key numbers; short text with "Tell me more" |
| 2.3 Respect across languages and dialects | Spanish infrastructure in place (student-facing Spanish is being translated); home-language interviews welcomed |
| 2.4 Bias in language and symbols | Language reviewed for gendered and ableist terms (none found) |
| 2.5 Multiple media | Text, diagrams, 3D models, sliders, Show Me steps, real-object labs |
| 3.1 Connect prior knowledge | "Builds on" on the goal card; prediction questions before each concept |
| 3.2 Patterns, critical features, big ideas | Fail gallery, find-the-problem hotspots, matching cause → effect |
| 3.3 Multiple ways of knowing | Hands-on labs (calipers, fit tests, strength tests), CAD, interviews, sketches |
| 3.4 Transfer and generalization | Real-world openers; capstone and mini design sprint with real users |

## Action & Expression — the "how" of learning

| Consideration | Where it shows up |
|---|---|
| 4.1 Methods for response and navigation | Keyboard-operable questions (ordering has move buttons; 3D viewer arrow keys); one-step-at-a-time navigation; Tinkercad tasks labelled with a button that opens a new tab |
| 4.2 Accessible materials and assistive tech | Works with screen readers (labels, live regions); **Speak instead** dictation on reflections, journals and written evidence; printable handouts for offline work |
| 5.1 Multiple media for communication | Evidence as design link, STL, screenshot **or photo**, physical test, or **written/spoken explanation** (design-process lessons) |
| 5.2 Multiple tools for construction | Tinkercad, paper sketches, cardboard prototypes, calipers; dictation |
| 5.3 Graduated support | Hints → feedback → explanation after repeated tries; Show Me steps; sentence starters |
| 5.4 Biases in modes of expression | Spoken and written explanations count for design-process evidence; photos of paper work accepted |
| 6.1 Meaningful goals | Goal card; requirement checklists students tick as they go |
| 6.2 Anticipate and plan | Plan-your-build ordering questions; boss "plan your attack"; **Stuck?** strategies |
| 6.3 Organize information and resources | Mission path, review deck, design journal |
| 6.4 Monitor progress | Progress bar and phases, XP and streaks, requirement checklists, mastery levels |
| 6.5 Challenge exclusionary practices | Design for everyone; team option; no-printer and touch-device alternatives in every teacher guide |
